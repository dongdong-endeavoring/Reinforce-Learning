## 随机性和证据
### 概率与统计复习
1. 贝叶斯定理：对于任何正概率事件A和B, $P(A | B) = \frac{P(B | A) P(A)}{P(B)}$
2. 一般贝叶斯定理:   

|              | Y discrete                                                           | Y continuous                                                            |
| :----------: | :------------------------------------------------------------------: | :---------------------------------------------------------------------: |
| X discrete   | $P(Y = y \mid X = x) = \frac{P(X = x \mid Y = y)P(Y = y)}{P(X = x)}$ | $f_Y(y \mid X=x) = \frac{P(X=x \mid Y=y)f_Y(y)}{P(X=x)}$                |
| X continuous | $P(Y=y \mid X=x) = \frac{f_X(x \mid Y=y)P(Y=y)}{f_X(x)}$             | $f_{Y \mid X}(y \mid x) = \frac{f_{X \mid Y}(x \mid y) f_Y(y)}{f_X(x)}$ |
3. 全概率公式：

|              | Y discrete                                                           | Y continuous                                |
| :----------: | :------------------------------------------------------------------: | :---------------------------------------------------------------------: |
| X discrete   | $P(X = x) = \sum\limits_y P(X = x \mid Y = y)P(Y=y)$ | $P(X=x) = \int_{-\infty}^{\infty} P(X=x \mid Y=y)f_Y(y)dy$                |
| X continuous | $f_X(x) = \sum\limits_{y}f_X(x \mid Y=y)P(Y = y)$             | $f_X(x) = \int_{-\infty}^{\infty} f_{X \mid Y}(x \mid y)f_Y(y)dy$ |
4. 贝叶斯角度认识概率： 
	- 概率是一种信念
	- 先验概率 + 证据 = 更新后的概率

### 期望 & 条件期望
1. 强化学习基于奖励假设
	- 定理：所有目标都可以通过最大化期望累积值来描述奖励
2. 定义：
	- 期望可以理解为长期平均
	- 对于一个离散随机变量：$E[X] = \sum\limits_{x}x P(X = x)$
	- 对于一个连续随机变量：$E[X] = \int xf(x) dx$
3. 期望的线性性质：
	- $E[aX + bY] = aE[X] + bE[Y]$
	- 不需要任何的独立性
4. 条件期望：
	- 条件期望是计算期望的一个强大工具：一步分析法  
	- 条件期望使我们能够根据当前可获得的证据来预测或估计未知量
	- 给定事件的条件期望：$E(Y \mid X)$
	- 给定随机变量的条件期望: $E(Y \mid X)$
5. 给定事件的条件期望：
	- 设 A 是一个概率大于零的事件
        - 如果 Y 是一个离散型随机变量，则在给定 A 的条件下，Y 的条件期望为：
		   $$ E(Y \mid A) = \sum\limits_{y}y P(Y = y \mid A) $$
		   其中求和是对Y的支撑集进行的
        - 如果Y是一个具有概率密度函数f的连续型随机变量， 则：
		   $$ E(Y \mid A) = \int_{-\infty}^{\infty} y f(y \mid A) dy $$  
		   其中条件概率密度函数PDF $f(y \mid A)$ 定义为条件累积分布函数CDF $F(y \mid A) = P(Y \leq y \mid A)$的导数，也可通过贝叶斯规则的混合版本进行计算：
		   $$ f(y \mid A) = \frac{P(A \mid Y = y)f(y)}{P(A)} $$
6. $E(YI \mid A)$的直观理解：
    - 定理：$E(Y \mid A)$ 大约等于在大量模拟运行中，当事件 A 发生时 Y 的平均值。
7. 全期望公式：设$A_1, ..., A_n$是样本空间的一个划分，且对所有$i$都有$P(A_i) \gt 0$, 同时$Y$是该样本空间上的一个随机变量。那么：
    $$ E(Y) = \sum\limits_{i = 1}^n E(Y \mid A_i) P(A_i)  $$
8. RL角度的条件期望：
    - RL元素：
        - 奖励：$R_t$
        - 状态：$S_t$
        - 行动：$A_t$
        - 返回：$G_t = \sum\limits_{k \geq 0} {\gamma}^{k} R_{t + k  + 1}$
          也可以写成$G_t = R_{t + 1} + \gamma R_{t + 2} + {\gamma} ^ 2 R_{t + 3} + ...$
    - 价值函数：
          - $V^{\pi}(s) = E_{\pi}[G_t \mid S_t = s]$
          - 价值函数不是一个确定性的评分，而是当前状态下多种可能未来情况的平均值
    - 离散条件期望公式
        - 直觉：$E[X \mid Y = y]$ 是在观察到 $Y = y$ 后对 $X$ 的最佳平均预测
        - 离散条件期望公式：$E[X \mid Y = y] = \sum\limits_x x P(X = x \mid Y = y)$
        - RL角度解读：$E[R_{t + 1} + \gamma V(S_{t + 1}) \mid S_t = s, A_t = a]$， 这意味着在固定当前状态-动作对后，将一步奖励与未来价值取平均
    - 状态将可能的未来划分为若干部分，价值是这些未来加权平均的结果
9. 给定随机变量的条件期望：
     - 定义：记 $g(x) = E(Y \mid X = x)$，那么，给定 $X$ 的 $Y$ 的条件期望，记作 $E(Y \mid X)$，被定义为随机变量 $g(X)$。换句话说，如果在进行实验后，$X$ 聚集为 $x$，那么 $E(Y \mid X)$ 就会聚集为 $g(x)$
     - $E(Y \mid X)$ 是 $X$ 的一个函数，并且它是一个随机变量
     - 由此可见，计算 $E(E(Y \mid X))$ 和 $Var(E(Y \mid X))$ 是合理的
     - 三大性质：
         1\) 如果 $X$ 和 $Y$ 独立，那么 $E(Y \mid X) = E(Y)$
         2\) 对于任意函数h, 都有 $E(h(X) Y  \mid X) = h(X) E(Y \mid X)$
         3\) 线性性质：$E(Y_1 + Y_2 \mid X) = E(Y_1 \mid X) + E(Y_2 \mid X)$
      - 亚当定律：
        - 基本形式：对于任意随机变量 $X$ 和 $Y$, $E(E(Y \mid X)) = E(Y)$
        - 证明：$E(E(Y \mid X)) = \int_{-\infty}^{\infty}[\int_{-\infty}^{\infty} y f_{Y \mid X}(y \mid x) dy] f_X(x) dx = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} y f_{X, Y}(x, y) dydx = \int_{-\infty}^{\infty} y f_Y(y) dy = E(Y)$
        - 额外条件下的亚当公式：对于任意随机变量X, Y, Z, 我们都有：
           $$ E(E(Y \mid X, Z) \mid Z) = E(Y \mid Z) $$
           $$ E(E(X \mid Z, Y) \mid Y) = E(X \mid Y) $$
       - 条件方差
        - 给定 $X$ 后 $Y$的条件方差 $Var(Y \mid X) = E((Y - E(Y \mid X))^2 \mid X)$.  
           等价于 $Var(Y \mid X) = E(Y^2 \mid X) - (E(Y \mid X))^2$
       - 夏娃定律：对于任意随机变量 $X$ 和 $Y$， $Var(Y) = E(Var(Y \mid X)) + Var(E(Y \mid X))$
### 条件期望的投影几何解释
1. 预测和估计
    - 根据观测值 $X$ 估计 $Y$
    - 选择估计函数（推断函数）$g(·)$，以最小化期望误差 $E(c(Y, g(X)))$  
       其中 $c(Y, \hat{Y})$ 表示当真实值为 $Y$ 时，猜测 $\hat{Y}$ 所产生的代价
    - 当 $c(Y,\hat{Y}) = ||Y − \hat{Y}||^ 2$ 时，该最优估计称为给定 $X$ 估计 $Y$ 的“最小二乘估计（LSE）”
    - 此外，如果函数 $g(·)$ 被限制为线性形式，即 $a + bX$，则称为给定 $X$ 时 $Y$ 的“线性最小二乘估计（LLSE）”
    - 此外，如果函数 $g(·)$ 可以任意选择，则称其为给定 $X$ 时 $Y$ 的“最小均方估计（MMSE）”
2. 线性最小二乘估计
    - 定理：给定 $X$ 时 $Y$ 的线性最小二乘估计（LLSE)，记作$L[Y \mid X]$，是使 $E[(Y - a - bX)^2]$ 最小的线性函数 $a + bX$，事实上
	   $$ L[Y \mid X] = E(Y) + \frac{Cov(X, Y)}{Var(X)} (X - E(X)) $$
3. 最小均方误差估计器
    - 定理：给定 $X$ 时 $Y$ 的最小均方误差由下式给出
      $$ g(X) = E[Y \mid X] $$
4. 投影解读
    - 定理：对于任意函数 $h$，随机变量 $Y − E(Y \mid X)$ 与 $h(X)$ 不相关， 这等价于
      $$ E((Y - E(Y \mid X))h(X)) = 0 $$
	  这是等价的是因为根据线性性质和亚当定律，$E(Y - E(Y \mid X)) = 0$
5. 预测视角
     - 根据数据预测或估计未来的观测值或未知参数
     - $E(Y \mid X)$ 是我们基于 $X$ 对 $Y$ 的最佳预测
     - 最佳意味着它是具有最小均方误差的 $X$ 函数（即 $Y$ 与 $Y$ 预测值之间期望平方差的最小值）
6. MMSE的正交性性质
     - 定理1：对于任意函数$\phi(·)$，$E[(Y - E[Y \mid X]) \phi(X)] = 0$
     - 定理2：此外，如果函数 $g(X)$ 满足 $$E[(Y - g(X)) \phi(X)] = 0\forall \phi(·)$$    则 $g(X) = E(Y \mid X)$
7. 联合高斯（正态）随机变量的最小均方误差
     - 定理： 设 $X$ 和 $Y$ 为联合高斯随机变量。则
       $$ E[YI \mid X] = L[Y \mid X] = E(Y) + \frac{Cov(X, Y)}{Var(X)} (X - E(X)) $$
8. 备注：统计学习视角
     - 通常情况下，MMSE 是一个高度非线性的函数
     - 采用不同的近似方法会导致不同的学习方法
         - 线性回归
         - 逻辑回归
         - 多项式回归
         - 样条函数回归
         - 神经网络

### 集中不等式
1. 蒙特卡洛估计
   - 蒙特卡洛估计器（样本均值）
     - 假设 $X_1. ... , X_n$ 是来自与 X 相同分布的独立同分布样本， 则$\hat{\mu}_n = \frac{1}{n} \sum\limits_{i = 1}^n X_i$
     - 三大性质：
       1）无偏性：$E[\hat{\mu}_n] = \mu$
       2）方差缩小: $Var(\hat{\mu}_n) = \frac{{\sigma}^2}{n}$​
       3）核心思想：蒙特卡洛方法用经验平均值来替代期望值
2. 强化学习中的蒙特卡洛价值估计
    - 目标：估计 $V^{\pi}(s) = E_{\pi}[G_t] S_t = s]$
    - 定理：如果我们观察到状态 $s$ 被访问了 $N(s)$ 次，并获得了回报 $G^{(1)}, ... , G^{N(s)}$, 那么
      $$ \hat{V}(s) = \frac{1}{N(s)} \sum\limits_{i=1}^{N(s)} G^{(i)} $$
    - 限制：蒙特卡洛方法必须等待完整回报序列才能学习的特点
3. 大数定律
    - 大数定律：对于独立同分布的样本 $X_1. X_2, ...$， 其均值为 μ，那么
     $$ \hat{\mu}_n = \frac{1}{n} \sum\limits_{i=1}^n X_i \to \mu $$
    - 大数定律告诉我们更多的样本最终会有帮助
    - 大数定律不能告诉我们在有限的n下，多少样本才算足够
4. 中心极限定理：误差的分布形态
    - 中心极限定理：对于大数n, 
      $$ \frac{\hat{\mu}_n - \mu}{\sigma / \sqrt{n}} \approx \mathcal{N}(0, 1) $$
      典型的误差尺度为 $O(\frac{1}{\sqrt{n}})$
5. 柯西舒瓦茨不等式：
    - 定理：对于任意具有有限方差的随机变量 $X$ 和 $Y$，
      $$ \lvert {E(XY)} \rvert \leq \sqrt{E(X^2)E(Y^2)} $$ 
6. Jensen不等式：
    - 定理1：如果 $f$ 是一个凸函数, 且 $o \leq \lambda_1, \lambda_2 \leq 1, \lambda_1 + \lambda_2 = 1$, 则对于任意 $x_1, x_2$, 
      $$ f(\lambda_1 x_1 + \lambda_2 x_2) \leq \lambda_1 f(x_1) + \lambda_2 f(x_2) $$
      ![[凸函数的Jensen不等式.png]]
    - 定理2：设 $X$ 是一个随机变量。
      $$
      \begin{cases}
      如果 g 是一个凸函数，则 E(g(X)) \geq g(E(X)) \\ 
      如果 g 是一个凹函数，则 E(g(X)) \leq g(E(X))
      \end{cases}
     $$
     在这两种情况下，等号成立的唯一条件是存在常数 $a$ 和 $b$，使得 $g(X) = a + bX$ 的概率为 $1$
7. 熵
    - 定义：设 $X$ 是一个离散型随机变量，其可能取的不同值为 $a_1, a_2, ... , a_n$，对应的概率分别为 $p_1, p_2, ... , p_n$, 即 $p_1 + p_2 + ... + p_n = 1$ , 那么 $X$ 的熵定义为：
      $$ H(X) = \sum_{j=1}^n p_j log_2(\frac{1}{p_j}) $$
    - 利用Jensen不等式，可以证明当随机变量 $X$ 的分布为 $a_1, a_2, ..., a_n$ 上的均匀分布时，其熵达到最大值，即对所有 $j$，$p_j = \frac{1}{n}$恒成立。 这在直觉上是合理的，因为当X取其各个值的可能性相等时，学习X的值所传递的信息量平均最大；而当X为常数时，所能提供的信息量则最小。
8. KL散度（Kullback–Leibler 散度）
    - 定义：设 $p = (p_1, ..., p_n)$ 和 $r = (r1, ... , r_n)$是两个概率向量（即每个分量均为非负数，且总和为1）。可将它们视为某个随机变量的可能的概率质量函数(PMF)，该随机变量的取值范围包含 $n$ 个不同的值。这个 $p$ 与 $r$ 之间的 KL散度定义为
      $$ D(\mathbf{p}, \mathbf{r}) = \sum\limits_{j=1}^n p_j log_2(\frac{1}{r_j}) - \sum\limits_{j=1}^n p_j log_2(\frac{1}{p_j}) $$
    - KL散度是非负的
9. 马尔可夫不等式：
    - 定理：对于任意随机变量 $X$ 和大于0的常数 $a$, 
      $$ P(\lvert X \rvert \geq a) \leq \frac{E \lvert X \rvert}{a} $$
10. 切比雪夫不等式
    - 定理：设 $X$ 的平均值为 $\mu$，方差为 ${\sigma}^2$. 那么对于任意 $a \gt 0$, 
      $$ P(\lvert X - \mu \rvert \geq a) \leq \frac{{\sigma}^2}{a^2} $$
11. 切尔诺夫不等式
     - 定理： 对于任意随机变量 $X$ 以及常数 $a \gt 0$ 和 $t \gt 0$, 
       $$ P(X \geq a) \leq \frac{E(e^{tX})}{e^{ta}} $$
12. 切尔诺夫界
     - 定理：对于任意随机变量 $X$ 和常数 $a$, 
       $$ P(X \geq a) \leq \inf_{t \gt 0} \frac{E(e^{tX})}{e^{ta}} $$
       $$ P(X \leq a) \leq \inf\limits_{t \lt 0} \frac{E(e^{tX})}{e^{ta}} $$
13. 霍夫丁引理
     - 定理：设随机变量 $X$ 满足 $E(X) = 0$, 且 $a \leq X \leq b$, 其中 $a$ 和 $b$ 为常数。那么对于任意$\lambda \gt 0$, 
       $$ E(e^{\lambda X}) \leq e^{\frac{1}{8} {\lambda}^2 (b - a)^2} $$
14. 霍夫丁不等式
     - 定理：设随机变量 $X_1, X_2, ... , X_n$ 相互独立，且 $E(X_i) = \mu$, 对每个 $i = 1, ... , n$都有 $a \leq X_i \leq b$, 其中 $a$、$b$ 为常数。那么对于任意 $\epsilon \geq 0$, 
       $$ P(\lvert \frac{1}{n} \sum\limits_{i=1}^n X_i - \mu \rvert \geq \epsilon) \leq 2 e^{- \frac{2n{\epsilon}^2}{(b - a)^2}} $$
     - 在有界独立样本下的标准形式：如果 $X_i \in [a, b]$ 相互独立且 $E[X_i] = \mu$, 则
       $$ P(\lvert \hat{\mu}_n - \mu \rvert \geq \epsilon) \leq 2 e^{- \frac{2n{\epsilon}^2}{(b - a)^2}} $$
         - $[0, 1]$ 内的奖励: $P(\lvert \hat{\mu}_n - \mu \rvert \geq \epsilon) \leq 2e^{-2n{\epsilon}^2}$
     - 更一般的形式：设随机变量 $X_1, X_2, ... , X_n$ 相互独立， 且对每个 $k$ 都有 $a_k \leq X_k \leq b_k$, 其中 $a_k$ 和 $b_k$ 为常数。令 $S_n = \sum_{k=1}^n X_k$， 且 $\mu = E(S_n)$. 那么对于任意 $t \gt 0$, 
       $$ P(\lvert S_n - \mu \rvert \geq t) \leq 2 e^{- \frac{2t^2}{\sum_{k=1}^n (b_k - a_k)^2}} $$
15. 从霍夫丁到置信半径
     - 对于奖励值在 $[0, 1]$ 范围内: $P(\lvert \hat{\mu}_n - \mu \rvert \geq \epsilon) \leq 2e^{-2n{\epsilon}^2}$
     - 将失败概率设为 $\delta$
     - 求解 $\epsilon$: $\epsilon = \sqrt{\frac{log(\frac{2}{\delta})}{2n}}$
     - 置信区间：$\mu \in [\hat{\mu}_n - \sqrt{\frac{log(\frac{2}{\delta})}{2n}}, \hat{\mu}_n + \sqrt{\frac{log(\frac{2}{\delta})}{2n}}]$
     - 这个随机区间有至少 $1 - \delta$ 的概率覆盖 $\mu$
     - 样本量小，置信区间宽；样本量大，置信区间窄
16. 上置信界算法
    - 经验估计：$\hat{\mu}_a$
    - 置信奖励：$\sqrt{\frac{2 log t}{N_t(a)}}$
    - 上置信界(UCB): $A_t = arg \max\limits_a[\hat{\mu}_a + \sqrt{\frac{2logt}{N_t(a)}}]$
17. 小结
    - 从期望到有限样本的信任
        - $\mu = E[X]$  未知的人口数量
        - $\hat{\mu}_n = \frac{1}{n} \sum\limits_{i=1}^{n} X_i$ 可观测样本估计
        - $P(\lvert \hat{\mu}_n - \mu) \geq \epsilon) \leq \delta$
        - 主要动因
            - LLN 表示：最终是正确的。  
            - 大数定律表示：在有限样本下具有可靠性。

### 马尔可夫动力学1
1. 随机过程
    - 定义：随机过程是一系列按时间索引的随机变量：
      $$ X_0, X_1, X_2, ...$$
    - RL 例子：
        - 状态流程：$S_0, S_1, S_2, ...$
        - 行动流程：$A_0, A_1, A_2, ...$
        - 奖励流程：$R_1, R_2, R_3, ...$
     - 核心想法：序列学习是从一个随机过程中进行学习，而不是从静态数据中学习数据集
     - 更一般的定义：
         - 随机过程是一组随机变量 $\{X_t, t \in I\}$的集合。集合 I 是该过程的指标集， 这些随机变量定义在同一个状态空间 $S$上
            - I 是离散的：离散时间随机过程（随机变量序列）
            - I 是连续的：连续时间随机过程（不可数的随机变量集合）
2. 随机建模中的模型选择
    - 足足够的复杂性，以捕捉所讨论现象的复杂性
    - 足够的结构和简洁性，足以让人计算出感兴趣的内容
3. 马尔可夫模型
    - 马尔可夫模型的三个基本组成部分：  
       1）一组随机变量 $\{X_t, t \in \mathcal{T}\}$，其中 $\mathcal{T}$ 是一个指标集，通常称为“**时间**”
       2）$\{X_t, t \in T\}$ 的所有可能取值称为“**状态**”，这些状态是状态空间 $\mathcal{S}$ 中的元素
       3）“**马尔可夫性质**”：给定过程的当前值（信息）时，该过程未来的演变与过去的发展无关
4. 马尔可夫模型的分类
    - 离散时间马尔可夫链：状态空间$\mathcal{S}$离散，时间$\mathcal{T}$离散  
    - 连续时间马尔可夫链：状态空间$\mathcal{S}$离散，时间$\mathcal{T}$连续
    - 离散马尔可夫过程：状态空间$\mathcal{S}$连续，时间$\mathcal{T}$离散  
    - 连续马尔可夫过程：状态空间$\mathcal{S}$连续，时间$\mathcal{T}$连续  
5. 马尔可夫链
    - 定义：若随机变量序列 $X_0, X_1, X_2, ...$ 取值于状态 $\{1, 2, ... , M\}$，且对所有 $n \geq 0$，满足:
      $$ P(X_{n + 1} = j \mid X_n = i, X_{n - 1} = i_{n - 1}, ... ,X_0 = i_0) = P(X_{n + 1} = j \mid X_n = i) $$
      ![[马尔可夫链.png]]
6. 时齐马尔可夫链
    - 定义：给定一个马尔可夫链 $X_0, X_1, X_2, ...$ 如果对所有 n ≥ 0，该链满足
      $$ P(X_{n + 1} = j \mid X_n = i) = q_{i, j} $$
    则称其为时间齐次马尔可夫链， 其中 $q_{i, j}$ 是与 $n$ 无关的常数
    - 从现在起，我们关注时齐马尔可夫链，并简称为马尔可夫链
7. 转移矩阵
    - 定义：设 $X_0, X_1, X_2, ...$ 是一个状态空间 $\{1, 2, ... , M\}$ 的马尔可夫链，令 $q_{i, j} = P(X_{n + 1} = j \mid X_n = i)$ 表示从状态 $i$ 转移到状态 $j$ 的转移概率。则 $M \times M$  矩阵 $Q = (q_{i, j})$ 称为该链的转移矩阵。
    - 每一行都是一个概率分布:
      $$ q_{i, j} \geq 0, \text{     } \sum_{j} q_{i, j} = 1 $$
    - 马尔可夫链的图示形式与矩阵形式:   
       ![[马尔可夫链的图示形式与矩阵形式.png]]
8. $n$步转移概率
    - 定义：设 $X_0, X_1, X_2, ...$ 是一个转移矩阵为 $Q$ 的马尔可夫链。从状态 $i$ 经过 $n$ 步转移到状态 $j$ 的概率，是指从状态 $i$ 出发，恰好经过 $n$ 步后到达状态 $j$ 的概率。我们用 $q_{i, j}$ 表示这一概率。
      $$ q_{i, j}^{(n)} = P(X_n = j \mid X_0 = i) $$
    - $2$步转移概率：
      $$ q_{i, j}^{(2)} = P(X_2 = j \mid X_0 = i) = \sum\limits_{k} q_{i, k}q_{k, j} = (i, j) \text{ entry of } Q^2 $$
    - 查普曼-科莫戈罗夫关系:
      $$ q_{i, j} ^ {(m + n)} = P(X_{m + n} = j \mid X_0 = i) = \sum\limits_k q_{i, j}^{(m)} q_{k, j}^{(n)} = (i,j) \text{ entry of } Q^{m + n} $$
9. 分布演化
    - 设 $\mu_n$ 为 $X_n$ 的行向量分布：
      $$ \mu_n(i) = P(X_n = i) $$
      则
      $$ \mu_{n + 1} = \mu_n Q $$
      通过迭代,
      $$ \mu_n = \mu_{0} Q^n $$
    - RL连接：策略与环境动态共同作用，在状态空间上诱导出一个马尔可夫链

### 马尔可夫动力学2
1. 常返态与瞬变态
    - 马尔可夫链中的状态 $i$ 是常返的，当且仅当从状态 $i$出发，链最终返回到i的概率为 $1$。否则，该状态是瞬态的，这意味着如果链从状态 $i$开始，存在正概率使其永远不再返回到 $i$
2. 不可约链与可约链
    - 定义：若一个马尔可夫链的转移矩阵为 $Q$，且对于任意两个状态 $i$ 和 $j$，都存在有限步数（以正概率）从 $i$ 到达 $j$，则称该马尔可夫链是不可约的。也就是说，对于任意状态 $i$ 和 $j$，都存在某个正整数 $n$，使得 $Q^n$ 的 $(i, j)$ 元素为正。反之，不满足此条件的马尔可夫链称为可约的
    - 不可约性蕴含所有状态均为常返:
        - 定理：在一个有限状态空间的不可约马尔可夫链中，所有状态都是常返的
3. 周期
    - 定义：对于一个转移矩阵为 $Q$ 的马尔可夫链，状态 $i$ 的周期 $d(i)$ 是所有可能返回时间集合的最大公约数, 那就是说
      $$ d(i) = gcd\{ n \gt 0: Q_{i, i}^n \gt 0 \} $$
      如果 $d(i) = 1$，则称状态 $i$ 是非周期的。如果返回时间的集合为空，则令 $d(i) = +\infty$ 
4. 周期性马尔可夫链、非周期性马尔可夫链
    - 周期性马尔可夫链定义：如果一个马尔可夫链是不可约的，并且所有状态的周期都大于 $1$，则称其为周期性马尔可夫链   
      ![[周期性马尔可夫链.png]]
    - 非周期性马尔可夫链定义：如果一个马尔可夫链是不可约的，并且所有状态的周期都等于 $1$，则称其为非周期马尔可夫链
5. 稳态分布
    - 定义：一个分布 $\pi$ 是稳态的，如果
      $$ \pi = \pi Q $$
    - 这意味着：如果 $X_n$ ~ $\pi$, 那么 $X_{n + 1}$ ~ $\pi$
	- RL角度：在固定策略下，长期状态访问模式通常由平稳分布或折扣占用度量来描述
6. 细致平衡
	- ![[细致平衡.png]]
	- 细致平衡蕴含平稳性
		- 对于每个目标状态 $i$, 
		    $$ (\pi Q)_i = \sum_j \pi_j q_{j, i} $$
		    通过细致平衡，
		    $$ \pi_j q_{i, j} = \pi_i q_{i, j} $$
		    所以，  
		    $$ (\pi Q)_i = \sum_j \pi_i q_{i, j} = \pi_i \sum_j q_{i, j} = \pi_i $$
		    从而得出结论：
		    $$ \pi Q = \pi $$
7. 可逆性
    - 定义：设 $Q= (q_{i, j})$ 为一个马尔可夫链的转移矩阵。假设存在 $s = (s_1, ... , s_M)$，其中 $s_i \geq 0$，且 $\sum_i s_i = 1$，使得对所有状态 $i$ 和 $j$，都有
      $$ s_i q_{i, j} = s_j q_{j, i} $$
      这个方程被称为可逆性或细致平衡条件，如果该条件成立，则称该链相对于 $s$ 是可逆的
8. 检查细致平衡方程
    - 定理：对于一个不可约的马尔可夫链，若其转移矩阵为 $Q = (q_{i, j})$，且存在满足细致平衡方程
      $$ \pi_i q_{i, j} = \pi_j q_{j, i} $$
      对所有状态对 $i$, $j$ 成立的概率解 $\pi$, 那么则该马尔可夫链是正复发的、时间可逆的，且解 $\pi$ 是唯一的平稳分布
    - 推论（对称转移矩阵）：如果一个不可约马尔可夫链的转移矩阵 $Q$ 是对称的，那么所有状态上的均匀分布 $(\frac{1}{M}, \frac{1}{M}, ... , \frac{1}{M})$ 就是唯一的平稳分布。
9. 混合：遗忘初始状态
    - 假设两条链从不同的初始分布开始：$\mu_0, \mathcal{v}_0$  
      经过 $t$ 步
      $$ \mu_t = \mu_0 Q^t, \mathcal{v}_t = \mathcal{v}_0 Q^t $$
      那么有混合直觉：当 $t$ 很大时，若
      $$ \mu_0 P^t \approx \mathcal{v}_0 p^t \approx x $$
      则该链是混合的
    - RL中的含义：缓慢的混合意味着经验仍然高度相关，探索可能会变得困难
10. 总方差距离
    - 定义：对于有限空间上的两个分布 $p$ 和 $q$, 
      $$ \lvert \lvert p - q \rvert \rvert_{TV} = \frac{1}{2} \sum\limits_x \lvert p(x) - q(x) \rvert $$
    - 例：$p = (0.7, 0.3), q = (0.6, 0.4)$  
       &emsp;&emsp;$\lvert \lvert p - q \rvert \rvert _{TV}  = \frac{1}{2}(\lvert 0.1 \rvert + \lvert -0.1 \rvert) = 0.1$
11. 混合时间
    - 定义：一个常见的定义是
      $$ t_{mix}(\epsilon) = min\left\{t: \max\limits_{\mu_0} \lvert \lvert\mu_0 Q^t - \pi \rvert \rvert_{TV} \leq \epsilon \right\} $$

### 统计推断
1. 参数化统计推断
    - 引入：
        - 给定一个参数化分布模型（一组概率质量函数或概率密度函数）$\mathcal{F} = \{p(x; \theta) : \theta \in \mathcal{R}\}$
        - $\theta$ 是参数空间 $\mathcal{R}$ 中的一个未知参数
        - 现在从该模型中获得一个（随机）样本：$\mathbf{X} = (X_1, ... , X_n)$
        - 如何进行参数化统计推断？
    - 示例：
      $$ \left\{ p(x; \mu, \sigma) = \frac{1}{\sigma \sqrt{2\pi}} e^{- \frac{1}{2{\sigma}^2} (x - \mu)^2 }, \mu \in \mathbb{R}, \sigma \gt 0 \right\} $$
      ![[参数化分布模型.png]]
	- 贝叶斯方法与频率学派
	    - 差异与未知参数 $\theta$ 的性质有关
	    - **频率学派方法**：将 $\theta$ 视为未知常数：
	    - **贝叶斯方法**：将参数 $\Theta$ 视为具有先验（已知）分布的随机变量
2. 统计推断：频率学派视角
    - 典型框架
        - 经典统计学：未知常数 $\theta$
          ![[统计推断：频率学派视角——典型框架.png]]        
        - 假设检验 $H_0: \theta = \frac{1}{2} \text{ versus } H_1 : \theta = \frac{3}{4}$
        - 复合假设 $H_0: \theta = \frac{1}{2} \text{ versus } H_1 : \theta \neq \frac{1}{2}$
        - 估计：设计一个估计器 $\hat{\Theta}$，以“使估计误差 $\hat{\Theta} - \theta$ 保持较小”
    - 估计方法：最大似然估计MLE
        - 我们观察到一组特定的数据 $\mathbf{x} = (x_1, ... , x_n)$
        - 似然：在参数 $\theta$ 不同取值下，观测到数据 $x$ 的概率（或概率密度），即 $p(\mathbf{x}; \theta)$
        - 最大似然估计（MLE）是使似然函数 $p(x; \theta)$ 在所有可能取值中达到最大的参数 $\theta$ 的值，即
          $$ \hat{\theta} = arg max_{\theta} p(\mathbf{x}; \theta) $$
        - 独立情况下的最大似然估计
            - 随机样本：$\{ X_i \}$ 是独立同分布的，我们有
              $$ log[p(\mathbf{x; \theta})] = log \prod_{i=1}^n p(x_i; \theta) = \sum_{i=1}^n log[p(x_i; \theta)] $$
            - 因此，在独立情况下，最大似然估计MLE如下所示
              $$ 
              \begin{aligned}
              \hat{\theta} &= arg \max_{\theta} p(\mathbf{x}; \theta) \\
                           &= arg \max_{\theta} log[p(\mathbf{x}; \theta)] \\
                           &= arg \max_{\theta} \sum_{i=1}^n log[p(x_i; \theta)] \\ 
              \end{aligned}
            $$
3. 统计推断：贝叶斯学派视角
    - 典型框架
        - 未知  $\Theta$
            - 被视为一个随机变量
            - 先验分布 $p_{\Theta}$ or $f_{\Theta}$
        - 观察 $X$
            - 观测模型 $p_{X \mid \Theta}$ or $f_{X \mid \Theta}$
        - 使用适当的贝叶斯规则来求解: $p_{\Theta \mid X}(\cdot \mid X=x)$ or $f_{\Theta \mid X}(\cdot \mid X = x)$
          ![[统计推断：贝叶斯学派视角——典型框架.png]]
        - 先验的来源是什么
             - 对称
             - 已知范围
             - 更早的学习
             - 主观或随意
    - 贝叶斯统计推断的输出
      ![[贝叶斯统计推断的输出.png]]
    - 贝叶斯统计推断中的通用贝叶斯规则
         &emsp; 1\) $\Theta$ 离散, $X$ 离散:
             $$ p_{\Theta \mid X}(\theta \mid x) = \frac{p_{\Theta}(\theta) p_{(X \mid \Theta)}(x \mid \theta)}{\sum\limits_{\theta'} p_{\Theta}(\theta')p_{X \mid \Theta}(x \mid \theta')} $$
         &emsp; 2\) $\Theta$ 离散, $X$ 连续:
             $$ p_{\Theta \mid X}(\theta \mid x) = \frac{p_{\Theta}(\theta) f_{(X \mid \Theta)}(x \mid \theta)}{\sum\limits_{\theta'} p_{\Theta}(\theta')f_{X \mid \Theta}(x \mid \theta')} $$
         &emsp; 3\) $\Theta$ 连续, $X$ 离散:
             $$ f_{\Theta \mid X}(\theta \mid x) = \frac{f_{\Theta}(\theta) p_{(X \mid \Theta)}(x \mid \theta)}{\displaystyle\int f_{\Theta}(\theta')p_{X \mid \Theta}(x \mid \theta') d{\theta}'} $$
         &emsp; 4\) $\Theta$ 连续, $X$ 连续:
             $$ f_{\Theta \mid X}(\theta \mid x) = \frac{f_{\Theta}(\theta) f_{(X \mid \Theta)}(x \mid \theta)}{\displaystyle\int f_{\Theta}(\theta')f_{X \mid \Theta}(x \mid \theta') d{\theta}'} $$
    - 贝叶斯规则：贝叶斯视角
        - 定理：$A$ 代表认知，$B$ 代表数据，那么
          $$ P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)} $$
            - $P(A)$: 先验认知
            - $P(B)$: 证据
            - $P(B \mid A)$: 似然（在先验认知条件下数据的信息）
            - $P(A \mid B)$: 后验认知
    - 估算方法1：
         - 最大后验概率MAP
         - 给定观测值 $x$，最大后验概率MAP准则选择使后验概率（概率密度）$p_{\Theta \mid \mathbf{X}}(\theta \mid \mathbf{x})$  最大化的值 $\hat{\theta}$：
           $$ \hat{\theta} = arg \max_{\theta} p_{\Theta \mid \mathbf{X}} (\theta \mid \mathbf{x}) $$
           这等价于
           $$ \hat{\theta} = arg \max_{\theta} p_{\Theta}(\theta) p_{\mathbf{X} \mid \Theta}(\mathbf{x} \mid \theta) $$
	- 估算方法2：
	    - 后验均值：给定观测数据 $\mathbf{x}$, $\Theta$ 的估计值为 $\hat{\Theta} = E[\Theta \mid \mathbf{X} = \mathbf{x}]$   
	      现在，给定观测样本 $X$, $\Theta$ 的估计量为 $\hat{\Theta} = E[\Theta \mid \mathbf{X}]$
	- 共轭先验
	    - 在蒙特卡洛方法之前，后验计算十分困难
	    - 共轭先验：降低后验分布的计算复杂度
	    - 通俗地说，如果先验分布和似然模型使得先验分布与后验分布都属于同一分布族，则称该先验分布与似然模型共轭
	- 贝叶斯推断
	    - 将所有未知量视为随机变量
	    - 在贝叶斯方法中，我们将未知概率 $\theta$ 视为一个随机变量，并为 $\theta$ 赋予一个分布
	    - 这被称为先验分布，它反映了我们在观察抛硬币结果之前对 $\theta$ 真实值的不确定性
	    - 实验完成后，数据被收集，然后利用贝叶斯规则更新先验分布，从而得到后验分布，该分布反映了我们对参数 $\theta$ 的新信念
	    - 现在我们采用贝塔分布作为先验分布
4. 贝塔分布
    - 定义：若随机变量 $X$ 的概率密度函数为
      $$ f(x) = \frac{1}{\beta (a, b)} x^{a - 1} (1 - x) ^{b - 1} $$
      则称 $X$ 服从参数为 $a$ 和 $b$（$a \gt 0，b \gt 0$）的贝塔分布
      其中常数 $\beta(a, b)$ 的选择使得概率密度函数的积分等于 $1$
      这个式子记作 $X ~ Beta(a, b)$
      贝塔分布是均匀分布的一种推广
    - 贝塔分布的概率密度函数PDF
      ![[贝塔分布的概率密度函数PDF.png]]
    - 贝塔-二项共轭（贝塔分布在贝叶斯推断中用作二项分布参数先验）
      如果我们用贝塔分布 $Beta(a, b)$ 作为参数 $\theta$（比如成功概率）的先验，然后观测到 $n$ 次试验中有 $k$ 次成功、$n - k$ 次失败，那么**后验分布仍然是贝塔分布**，更新规则：
      $$ \theta \mid data ~ Beta(a + k, b + n - k) $$
      也就是说：
        - 把观测到的**成功次数** $k$ 加到贝塔分布的**第一个参数** $a$ 上
        - 把观测到的**失败次数** $n - k$ 加到贝塔分布的**第二个参数** $b$ 上
        
        这就是贝塔-二项共轭的“共轭”优势：后验和先验形式相同，只是参数变了
	    1\)  均值 vs. 贝叶斯（后验）平均  
        - 第1步：推断θ的值（硬币正面朝上的概率）
        - 第2步：$n$ 次抛硬币中观察到 $k$次正面
        - 第3步：平均值：$\frac{k}{n}$
        - 第4步：贝叶斯（后验）平均值：$\mathbb{E} (\theta \mid X = k) = \frac{a + k}{a + b + n}$
        - 第5步：假设先验分布为均匀分布 $Unif(0, 1): a = 1, b = 1$
        - 第6步：贝叶斯（后验）平均：$\frac{k + 1}{n + 2}$
        - 第7步：当 $k = n$，我们有 $1$ （平均值）vs. $\frac{n + 1}{n + 2}$ （贝叶斯平均）
        - 贝叶斯（后验）平均值
        
        2\) 先验平均：$\mathbb{E}(\theta) = \frac{a}{a + b}$
        &emsp; 贝叶斯（后验）平均：$\mathbb{E}(\theta \mid X = k) = \frac{a +k}{a + b + n}$

### RL角度的贝叶斯学习
1. 贝叶斯学习作为信念更新
     - 贝叶斯规则：
       $$ P(\theta \mid D) = \frac{P(D \mid \theta)P(\theta)}{P(D)} $$
       ![[贝叶斯学习作为信念更新.png]]
	   核心思想：贝叶斯学习保留不确定性，而不仅仅是点估计
2. 后验预测分布
    - 贝叶斯学习通过平均参数不确定性来预测未来的观测结果：
      $$ P(x_{new} \mid D) = \int P(x_{new} \mid \theta, D) P(\theta \mid D) d\theta $$
      1\) 贝塔-伯努利情况：下次成功的概率是
         $$ P(X_{new} = 1 \mid D) = \mathbb{E}[\theta \mid D] = \frac{\alpha + s}{\alpha + \beta + s + f} $$
      2\) 核心思想：贝叶斯预测通过整合不确定性，而非仅代入单一估计值
3. POMDP：部分可观测马尔可夫决策过程
   ![[POMDP：部分可观测马尔可夫决策过程.png]]
    - 部分可观测马尔可夫决策过程中的信念状态预览
        - 隐藏状态
        - 信念：
          $$ b_t(s) = P(S_t = s \mid O_{1:t}, A_{1:t - 1}) $$
          ![[部分可观测马尔可夫决策过程中的信念状态预览.png]]
    - 一步信念更新
        - 预测步骤：
          $$ \overline{b}_{t + 1}(s') = \sum_s P(s' \mid s, a_t) b_t(s) $$
        - 校正步骤：
          $$ b_{t + 1}(s') = \frac{P(o_{t + 1} \mid s') \overline{b}_{t + 1}(s')}{\sum_{x} P(o_{t + 1} \mid x) \overline{b}_{t + 1}(x)} $$
        - 核心思想：
